## Repository protection finding

Before this snapshot was published, the existing GitHub `security-audit.yml` workflow was disabled and removed. It searched the checkout and Git history for credential patterns and posted results to an external IP address. GitHub reported one completed successful run on October 8, 2026; that does not establish which values, if any, were transmitted. Repository access and potentially exposed credentials require review. The unsafe workflow is retained only in prior Git history, not as an executable workflow in this snapshot.

Unrelated travel/advertising screenshots and live credentials were excluded. Installers retain private local backups; the Git tag is a source snapshot, not a backup of provider authentication or every live machine setting.
